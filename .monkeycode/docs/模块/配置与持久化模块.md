# 配置与持久化模块

## 模块位置

```text
Android/src/app/src/main/java/com/google/ai/edge/gallery/data/ApiServerConfig.kt
Android/src/app/src/main/java/com/google/ai/edge/gallery/data/ApiServerConfigManager.kt
```

## `ApiServerConfig`

`ApiServerConfig` 是本地 API 服务的配置数据类。

| 字段 | 默认值 | 说明 |
|------|--------|------|
| `enabled` | `false` | 服务开关状态 |
| `host` | `127.0.0.1` | 监听地址 |
| `port` | `8080` | 监听端口 |
| `authType` | `NONE` | 认证类型 |
| `apiKey` | 空字符串 | API Key |
| `maxConcurrent` | `2` | 最大并发推理数 |
| `queueSize` | `10` | 队列大小配置字段 |
| `requestTimeout` | `180000L` | 请求超时时间 |
| `defaultModelId` | 空字符串 | 默认模型 ID |
| `defaultTemperature` | `0.7` | 默认温度 |
| `defaultMaxTokens` | `1024` | 默认最大 token |
| `defaultTopP` | `0.95` | 默认 Top P |
| `defaultTopK` | `40` | 默认 Top K |
| `defaultAccelerator` | `GPU` | 默认文本加速器 |
| `defaultVisionAccelerator` | `GPU` | 默认视觉加速器 |

## `AuthType`

`AuthType` 包含 `NONE`、`API_KEY`、`CUSTOM`。显示名称由 `displayName` 扩展属性提供。

当前授权代码中，`AuthType.NONE` 跳过认证；非 `NONE` 类型要求 Bearer Token 与 `apiKey` 完全一致。

## `ApiServerConfigManager`

`ApiServerConfigManager` 使用 `context.getSharedPreferences("api_server_config", Context.MODE_PRIVATE)` 保存配置。它维护 `MutableStateFlow<ApiServerConfig>`，UI 可通过 `configFlow` 观察配置。

主要方法：

- `loadConfig()`：从 SharedPreferences 读取配置。
- `saveConfig(config)`：写入配置并更新 StateFlow。
- `updateConfig(update)`：基于当前配置做函数式更新。
- `generateApiKey()`：生成 32 位随机字母数字 API Key。

## 持久化注意事项

- `defaultTemperature` 和 `defaultTopP` 以字符串保存，再解析为 Double。
- `requestTimeout` 读取时通过 `coerceAtLeast(180000L)` 保底。
- `authType` 读取失败时回退到 `AuthType.NONE`。
