# 设置界面模块

## 模块位置

```text
Android/src/app/src/main/java/com/google/ai/edge/gallery/ui/settings/ApiServerSettingsScreen.kt
```

## 页面职责

`ApiServerSettingsScreen` 是本地 API 服务的主要配置页面。它接收 `ModelManagerViewModel`，通过 `ApiServerViewModel` 读取服务状态和配置。

页面显示和配置内容包括：

- API 服务开关。
- 运行状态卡片。
- Host、端口、局域网 IP。
- 默认模型选择。
- API Key 认证配置。
- 默认温度、最大 token、Top P、Top K。
- 文本推理加速器。
- 视觉推理加速器。

## 状态来源

页面通过 `collectAsState()` 读取：

- `viewModel.serverStatus`
- `viewModel.serverInfo`
- `viewModel.configFlow`

已下载模型来自 `modelManagerViewModel.getAllDownloadedModels()`。

## 默认模型选择

页面遍历已下载模型列表，将 `model.name` 与 `config.defaultModelId` 对比确定选中状态。没有已下载模型时，页面提示先在 Models 中下载模型。

## 加速器选项

文本加速器选项优先使用选中模型的 `accelerators`。如果为空，则回退到 `Accelerator.values()`。视觉加速器选项使用 `Accelerator.values()`。

## 局域网 IP

页面通过 `NetworkInterface.getNetworkInterfaces()` 查找非 loopback 的 IPv4 地址，用于展示局域网访问地址。

## 与服务生命周期的关系

Switch 打开时调用 `viewModel.startServer(modelManagerViewModel)`，关闭时调用 `viewModel.stopServer()`。实际服务生命周期由 `ApiServerManager` 管理。
