# 日志与诊断

## 日志标记

本地 API 服务相关日志统一包含 `LOCAL_API` 标记，便于通过 Logcat 搜索。

## `HttpTrafficLogger`

`HttpTrafficLogger` 是 App 内日志聚合器，支持以下日志类型：

- `REQUEST`
- `RESPONSE`
- `ERROR`
- `DEBUG`
- `CRASH`

它维护一个最多 1000 条的内存队列，并将最近 100 条日志持久化到 `SharedPreferences("http_traffic_logs")`。

## 崩溃记录

`HttpTrafficLogger.initialize()` 会设置全局 uncaught exception handler。崩溃时记录线程名和堆栈，并调用原始 handler。

## 敏感信息处理

`ApiServer.safeHeaders()` 会将 `authorization` header 替换为 `<redacted>`，避免 API Key 出现在请求日志中。

## 异常日志增强

`HttpTrafficLogger.logException(tag, url, throwable)` 专用于记录推理级失败。它会提取完整 cause chain（`A: msg ← B: msg ← C: msg`）和根异常的 stack trace，一并写入 ERROR 日志。

`HttpTrafficLogger.formatExceptionChain(t)` 将异常链压缩为单行可读格式，方便日志检索和问题定位。

## 双写持久化

日志持久化采用异步 `apply()` + 同步 `commit()` 双保险：

- **普通日志**（REQUEST / RESPONSE / DEBUG / ERROR）：通过 `addEntry()` → `persistLogs()` 以 `apply()` 异步写入，不阻塞推理线程。
- **关键错误**（`logException` / `logCrash`）：额外调用 `persistLogsSync()` 以 `commit()` 同步强制落盘，确保进程被 OOM / SIGKILL 杀死前日志已写入文件系统。
- **全局崩溃处理器**：`setupCrashHandler()` 在崩溃时同样调用 `persistLogsSync()` 做最终落盘。

App 重启后 `loadPersistedLogs()` 从 `SharedPreferences` 加载最近 100 条日志。

## 常见事件

| 事件 | 来源 | 说明 |
|------|------|------|
| `server_started` | `ApiServer` | 服务启动成功 |
| `server_start_failed` | `ApiServer` | 服务启动失败 |
| `auth_failed` | `ApiServer` | 认证失败 |
| `models_list` | `ApiInferenceHandler` | 获取已下载模型列表 |
| `chat_start` | `ApiInferenceHandler` | 非流式聊天开始 |
| `chat_done` | `ApiInferenceHandler` | 非流式聊天完成 |
| `chat_error` | `ApiInferenceHandler` | 非流式推理失败（含完整 cause chain） |
| `chat_timeout` | `ApiInferenceHandler` | 非流式推理超时 |
| `chat_route_failed` | `ApiServer` | 非流式路由层捕获到的异常 |
| `chat_stream_start` | `ApiInferenceHandler` | 流式聊天开始 |
| `chat_stream_done` | `ApiInferenceHandler` | 流式聊天完成 |
| `chat_stream_error` | `ApiInferenceHandler` | 流式推理失败（含完整 cause chain） |
| `chat_stream_client_disconnected` | `ApiServer` 或 `ApiInferenceHandler` | 客户端断开流式连接 |
| `chat_stream_done_write_failed` | `ApiServer` | 流结束后补发 [DONE] 时 socket 已不可写 |
| `model_init_error` | `ApiInferenceHandler` | 模型初始化失败 |
| `request_error` | `ApiServer` | 请求处理阶段未预期异常 |
| `response_write_failed` | `ApiServer` | 错误响应写入 socket 失败 |
| `response_client_disconnected` | `ApiServer` | 写错误响应时客户端已断开 |
