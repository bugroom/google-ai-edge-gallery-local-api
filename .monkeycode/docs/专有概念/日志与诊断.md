# 日志与诊断

## 日志标记

本地 API 服务相关日志统一包含 `LOCAL_API` 标记，便于通过 Logcat 搜索。

## `HttpTrafficLogger`

`HttpTrafficLogger` 是 App 内日志聚合器，支持以下日志类型：

- `REQUEST`
- `RESPONSE`
- `ERROR`
- `DEBUG`
- `CRASH`

它维护一个最多 1000 条的内存队列，并将最近 100 条日志持久化到 `SharedPreferences("http_traffic_logs")`。

## 崩溃记录

`HttpTrafficLogger.initialize()` 会设置全局 uncaught exception handler。崩溃时记录线程名和堆栈，并调用原始 handler。

## 敏感信息处理

`ApiServer.safeHeaders()` 会将 `authorization` header 替换为 `<redacted>`，避免 API Key 出现在请求日志中。

## 常见事件

| 事件 | 来源 | 说明 |
|------|------|------|
| `server_started` | `ApiServer` | 服务启动成功 |
| `server_start_failed` | `ApiServer` | 服务启动失败 |
| `auth_failed` | `ApiServer` | 认证失败 |
| `models_list` | `ApiInferenceHandler` | 获取已下载模型列表 |
| `chat_start` | `ApiInferenceHandler` | 非流式聊天开始 |
| `chat_done` | `ApiInferenceHandler` | 非流式聊天完成 |
| `chat_stream_start` | `ApiInferenceHandler` | 流式聊天开始 |
| `chat_stream_done` | `ApiInferenceHandler` | 流式聊天完成 |
| `chat_stream_client_disconnected` | `ApiServer` 或 `ApiInferenceHandler` | 客户端断开流式连接 |
| `model_init_error` | `ApiInferenceHandler` | 模型初始化失败 |
